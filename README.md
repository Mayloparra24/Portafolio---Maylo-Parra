## 🚀 Inicio Rápido

### Requisitos Previos
- Node.js (v14 o superior)
- npm o pnpm

### Instalación

1. **Clonar el repositorio**
```bash
git clone https://github.com/Mayloparra24/Portafolio---Maylo-Parra.git
cd Portafolio
```

2. **Instalar dependencias**
```bash
npm install
# o con pnpm
pnpm install
```

3. **Ejecutar servidor de desarrollo**
```bash
npm run dev
```

4. **Abrir en el navegador**
```
http://localhost:1234
```

## 🎨 Personalización

### Cambiar Colores
Edita las variables CSS en `src/index.css`:

```css
:root {
    --primary: #00d4ff;      /* Cyan */
    --secondary: #ff006e;    /* Rosa */
    --accent: #8338ec;       /* Púrpura */
    /* ... más variables */
}
```

### Agregar Información Personal
1. Edita los textos en `src/index.html`
2. Actualiza tus datos en cada sección
3. Reemplaza proyectos con los tuyo propios
4. Actualiza enlaces de contacto

### Agregar CVs
Coloca tus archivos PDF en `/CVs/` con estos nombres:
- `CV_Maylo_Parra_ES.pdf` - CV en español
- `CV_Maylo_Parra_EN.pdf` - CV en inglés
